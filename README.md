<h1 align="center">★ Pixel Task Quest ★</h1>

<p align="center">Ретро-пиксельный трекер времени для задач на macOS.<br>
Нажимаешь «СТАРТ», работаешь, а кошечка Мяу-Луна, Моти и Звёздочка-фея тебя подбадривают.</p>

  <img src="docs/screenshot.svg" width="420" alt="Скриншот приложения">

## Возможности

- **Старт / стоп** одной кнопкой или **пробелом**
- **Список задач («квестов»)**: добавить, выбрать, удалить. Клик по другой задаче во время работы переключает таймер на неё
- **Время по каждой задаче** и **за сегодня**
- **Уровни**: каждые 25 минут работы за день дают новый LV и «LEVEL UP!»
- **Экспорт в CSV** (открывается в Excel) со всеми сессиями и итогами
- **Режим «поверх окон»** (кнопка TOP)
- Если закрыть окно при идущем таймере, время продолжит считаться до следующего запуска
- Данные сразу сохраняются в `tracker_data.json` рядом со скриптом

## Анимации

Пока таймер стоит, кошечка спит. Когда он идёт, все оживают: кошечка прыгает, Моти скачет и пускает сердечки, Звёздочка-фея летает и сыплет искорками. На фоне падает «цифровой дождь» из символов, как в «Матрице» (кнопка RAIN его выключает). На сцене есть облака, НЛО, падающие звёзды, блок-сюрприз с монетками, цветы и пиксельные стикеры вокруг.

Все персонажи и спрайты оригинальные и нарисованы прямо в коде строками пикселей.

## Запуск

Нужен только Python 3 с tkinter, сторонние библиотеки не требуются.

```bash
python3 pixel_tracker.py
```

Можно и двойным кликом по `Запустить трекер.command`.

### Приложение для macOS с иконкой

```bash
python3 build_app.py
```

Рядом появится `Pixel Task Quest.app`. Его можно перетащить в «Программы» или в Dock. Приложение запускает `pixel_tracker.py` из этой папки, поэтому после переноса папки его нужно пересобрать.

## Управление

| Действие | Как |
|---|---|
| Старт / стоп | кнопка или `Пробел` |
| Добавить задачу | ввести название и нажать `Enter` или `+` |
| Выбрать задачу | клик по строке |
| Удалить задачу | `✕` |
| Прокрутка списка | колесо мыши |
